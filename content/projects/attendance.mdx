An advanced AI-powered employee attendance system designed to automate timekeeping using state-of-the-art facial recognition technology. The system connects seamlessly to existing CCTV infrastructure via RTSP protocols using OpenCV, extracting live video frames for continuous real-time processing.

At the core of the AI pipeline is the InsightFace deep learning model, generating highly accurate facial embeddings regardless of lighting or angles. These embeddings are indexed and searched using Qdrant Vector DB, allowing for lightning-fast identity verification. All operational data, including employee profiles and attendance logs, is securely managed via MongoDB, providing administrators with a reliable and modern HR solution.
